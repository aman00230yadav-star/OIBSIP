## 📖 Report Overview

The report covers three major threat categories:

### 🔴 Denial-of-Service (DoS/DDoS) Attacks
How volumetric, protocol, and application-layer floods work — featuring the **Mirai botnet attack on Dyn (2016)**, which disrupted Twitter, Amazon, GitHub, and Netflix using hijacked IoT devices.

### 🔴 Man-in-the-Middle (MITM) Attacks
How attackers intercept communications via ARP spoofing, rogue Wi-Fi, SSL stripping, and DNS spoofing — including the **Firesheep** case that exposed the risks of unencrypted public Wi-Fi sessions.

### 🔴 Spoofing Attacks
IP, email, DNS, and MAC spoofing — how forged identities enable phishing, DNS poisoning, and amplification DDoS attacks.

Each section includes:
- ✅ How the attack works
- ✅ Real-world example
- ✅ Impact analysis
- ✅ Mitigation strategies

Plus a cross-cutting **Preventive Measures** section covering network segmentation, MFA, IDS/IPS monitoring, patching, and encryption best practices.
